# PC28 Audit Gate

当前项目不进入真钱、不继续 PPO 训练。后续推进顺序固定为：

`盘口 EV -> 状态统计 -> 规则过滤 -> holdout 验证 -> dry-run -> 再考虑 PPO`

## 当前结论

- 旧 PPO 结果不可作为决策证据：test 被反复使用，且旧结算口径曾污染结果。
- 旧 `extreme = 0-5 or 22-27` 单注覆盖双边的盈利结论作废。
- 旧组合过滤器报告只保留为排错记录，不作为上线依据。
- 新方向不是预测下一期，而是先确认真实盘口 EV，再用顺/反顺等状态做过滤。

## 真实盘口优先级

按用户提供的盘口，优先研究接近公平盘：

| 玩法 | 赔率含本金 | 理论定位 |
|---|---:|---|
| 大 / 小 / 单 / 双 | 1.98 | 接近公平，约 -1% ROI |
| 小单 / 大双 | 3.69 | 接近公平，约 -0.74% ROI |
| 小双 / 大单 | 4.29 | 接近公平，约 -0.90% ROI |
| 和值 8 / 19 | 22 | 接近公平，约 -1% ROI |
| 和值 9 / 18 | 18 | 接近公平，约 -1% ROI |

暂不作为主研究方向：

| 玩法 | 原因 |
|---|---|
| 极大 / 极小 16倍 | 理论 ROI 约 -10.4% |
| 顺子 17倍 | 直接下注理论 ROI 过低，只可做状态特征 |
| 豹子 / 对子 | 理论劣势较大或波动过高 |
| 13 / 14 单点 | 理论 ROI 过低 |

## 下一步

1. 更新结算赔率为真实盘口，而不是旧赔率表。已完成：
   - 大 / 小 / 单 / 双：1.98
   - 小单 / 大双：3.69
   - 小双 / 大单：4.29
   - 8 / 19：22，9 / 18：18
   - 极大 / 极小：16，顺子：17，对子：3.5，豹子：60
   - 13 / 14 不再走水或保本，按对应玩法正常赔付
2. 做盘口 EV 表，固定保留接近公平盘。已完成，见 `ai_agent/logs/state_stats_history_real_odds.md`。
3. 做顺/反顺状态统计。第一版已完成，见 `ai_agent/logs/state_stats_history_real_odds.md`：
   - 最近 N 期顺/反顺率
   - 顺/反顺后下一期四组合条件概率
   - 顺/反顺遗漏后的条件概率
   - 接近公平盘是否超过盈亏平衡点
4. 下一步只把显著状态转成规则过滤器。优先观察：
   - 上一期反顺 -> 双 / 大双 / 小双 / 和值8
   - 近 30/50 期反顺率偏高 -> 和值8 / 大单 / 大双
   - 上一期顺 -> 和值9 / 和值18 / 小双 / 大双
5. 固定规则后再做分段 holdout，禁止边看结果边改参数。第一版已完成，见 `ai_agent/logs/state_filter_20000_real_odds_segments.md`：
   - 上一期反顺 -> 大双：20 段中 11 段正收益，总 ROI 3.78%，最差回撤 1.00%
   - 上一期顺 -> 小双：20 段中 11 段正收益，总 ROI 2.50%，最差回撤 2.92%
   - 上一期顺 -> 和值9：20 段中 11 段正收益，总 ROI 1.96%，最差回撤 3.92%
   - 上一期顺 -> 和值18：20 段中 10 段正收益，总 ROI 9.37%，最差回撤 3.83%
   - 近30/50反顺率偏高 -> 和值8：分段稳定性不足，暂不采纳
6. 结论：第一版状态规则还未达到 dry-run 条件。下一步需要增加更严格的过滤，例如连续亏损暂停、只采纳正收益段稳定性更高的状态，或把规则按独立 holdout 再拆分验证。
7. 保守组合 v1 已完成，见：
   - `ai_agent/logs/state_filter_conservative_20000_real_odds_segments.md`
   - `ai_agent/logs/state_filter_conservative_2025_12_real_odds_segments.md`
   - 固定规则：上一期反顺下注大双，上一期普通顺下注小双。
   - 风控：warmup 100 期、至少 12 次历史信号、近 30 次信号为负则跳过、亏损后暂停 20 期、最高下注率 8%。
   - `data/pc28_round_20000_raw.jsonl`：20 段中 9 段正收益，总盈亏 +280.50，ROI 11.84%，最差回撤 0.75%，平均下注率 1.19%，结论不稳定。
   - `data/pc28_2025_12_raw.jsonl`：12 段中 4 段正收益，总盈亏 +148.80，ROI 12.72%，最差回撤 0.83%，平均下注率 0.97%，结论不稳定。
   - 长期 `data/pc28_keno_1995_2025_raw.jsonl`，每 10,000 期一段：338 段中 154 段正收益，总盈亏 -6011.10，ROI -1.31%，最差回撤 4.39%，平均下注率 1.36%，结论不稳定。
   - 判断：它做到低下注率、低回撤，但长期 ROI 回到庄家边际附近，不能进入 dry-run，应废弃为主策略。
8. 全量状态统计已完成，见 `ai_agent/logs/state_stats_keno_1995_2025_real_odds.md`：
   - 长期样本下，大多数玩法状态都落在约 -0.7% 到 -1.3% ROI 区间，接近盘口理论劣势。
   - 少数反顺率偏高状态出现正 ROI，例如 `近50/100反顺率偏高 -> 和值19`、`近100反顺率偏高 -> 小双/大单`，但这些只是状态统计候选，必须分段验证，不能直接下注。
   - 已验证的 `反顺/顺 -> 大双/小双` 保守版长期失败。
9. 只有 holdout 多段稳定后，才进入 dry-run。
